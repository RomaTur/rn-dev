# Происхождение реализации

Woodland — демонстрационное приложение для контроля качества древесины. Прикладной код, тексты, значки и данные подготовлены для этого проекта. Планшетная компоновка опирается на визуальные референсы.

Нативная основа использует открытый шаблон React Native. Лицензии React Native, React и AsyncStorage находятся в [docs/licenses](licenses/). Интерфейс использует системный шрифт Android.

Redux Toolkit, React Redux, React Navigation, React Native Screens, Reanimated и Worklets используются на условиях лицензий своих пакетов npm.

Gradle Wrapper 9.4.1 в `android/gradlew`, `android/gradlew.bat` и `android/gradle/wrapper/gradle-wrapper.jar` распространяется по [Apache License 2.0](licenses/apache-2.0.txt). В Windows-скрипте также сохранено уведомление React Native, относящееся к шаблону. Ресурс `android/app/src/main/res/drawable/rn_edit_text_material.xml` содержит уведомление об авторских правах Android Open Source Project и распространяется по той же лицензии Apache 2.0.

Отдельная лицензия на прикладной код Woodland не заявлена.

Скриншоты сняты с Woodland на Android-эмуляторе. PDF сформирован самим приложением из демонстрационного осмотра. Обе фотографии древесины сгенерированы для примера и помечены в отчёте как синтетические.
