# Android device adapter

`NativeModules.WoodlandDevice` implements `src/device/types.ts` through React Native's native-module interop. It is registered in `MainApplication` and requires no added npm package.

- `getIdentity()` returns the saved display name or `null`. It does not unlock the device boundary.
- `createIdentity(name, pin)` creates the single local inspector; `unlock(pin)` opens an in-memory session. Both accept a six-digit PIN. `lock()` closes the session. A process restart requires a new unlock. The native profile is a local demonstration gate, not remote authentication or independent identity verification.
- Credentials use 24 secure-random salt bytes and PBKDF2-HMAC-SHA256 (210,000 rounds, 256-bit output). The six-digit PIN is never persisted. Private preferences hold the salt, derived key, failure count and lockout deadline; comparisons use `MessageDigest.isEqual`. Five failures lock attempts for 15 minutes, including across restarts. After cooldown, another failure locks again until a successful unlock clears the count.
- `capturePhoto()` opens the installed camera app. Cancellation returns `null`; unavailable camera/activity and concurrent capture reject with an actionable error. A FileProvider grants temporary access only to a random capture file. The result is copied to private storage, decoded with dimension/byte limits, oriented from EXIF, then encoded as a new JPEG with no original metadata. Photo names are opaque `photo_<uuid>.jpg`; UI image URIs refer to app-private files.
- `pickDate(initial)` opens `DatePickerDialog`, returns `YYYY-MM-DD` or `null` on cancellation, and rejects future dates. Calendar-day validation uses GMT+3.
- `createPdf(inputJson)` accepts a report title, text lines, and up to 20 photo filename/caption pairs. It validates filenames and canonical ownership before reading attachments. It renders a paginated PDF with Cyrillic text, preserved paragraph breaks, wrapping and aspect-fit photos. Images are sampled to at most 1024 px in the PDF. The returned `pdf_<uuid>.pdf` stays in private storage.
- `openReport(fileName)` opens the app's private native `PdfRenderer` viewer, including on offline AOSP tablets without a PDF application. The explicit `ACTION_VIEW` intent carries an owned FileProvider URI, PDF MIME type and temporary read grant. Both dispatch and the UI thread require an unlocked session; the non-exported activity also rechecks that session and the opaque filename/canonical ownership. Pages default to fit-to-width with vertical scrolling for readable text; a 56 dp toggle switches to a whole-page overview. Close/Previous/Next controls are also 56 dp. It restores the page and display mode on rotation, and releases bitmaps, pages, document and file descriptor when stopped. Locking closes the viewer, and a process restart cannot restore report access without another unlock. Rendering runs off the UI thread with a 2048 px bitmap edge limit independent of the displayed page size. Resolution means the viewer launched; a damaged PDF shows an actionable Russian error inside it.
- `shareReport(fileName)` opens Android's PDF share chooser with a temporary read grant. Resolution means the chooser opened; it does not claim a recipient received a file. Only existing owned report filenames are accepted.

The manifest requests neither `CAMERA` nor storage permission: taking photos delegates to the installed camera app. The FileProvider exposes only the camera cache directory and report directory, never credentials or private photographs. Backup is disabled in the existing manifest.

The five JVM boundary tests cover a PBKDF2 known-answer comparison with the JCA provider, invalid filename/traversal rejection, lockout transitions, strict date parsing, and image sampling boundaries. Actual camera handling, native calendar rendering, PDF visual output, chooser behavior and restart persistence need Android integration verification.

Public Android references: [camera intent and output URI](https://developer.android.com/guide/components/intents-common), [minimal camera permissions](https://developer.android.com/privacy-and-security/minimize-permission-requests), [PdfDocument](https://developer.android.com/reference/android/graphics/pdf/PdfDocument).
